❓ راهنمای AI Chat Pro

💬 چت متنی

  • پیامت رو بنویس و ➤ بزن یا Enter بزن
  • از پرامپت‌های سریع پایین صفحه استفاده کن
  • هر provider مدل‌های خودش رو داره

🎨 تولید تصویر

  • Provider رو روی Pollinations بذار
  • پرامپت بنویس: مثلاً «یک گربه با عینک آفتابی»
  • بدون API key کار میکنه! ✅
  • مدل‌های خوب: flux، flux-realism، flux-anime

✏️ ویرایش تصویر با Pollinations

  • ⚠️ ویرایش تصویر نیاز به شارژ (pollen) داره
  • 🔗 شارژ از enter.pollinations.ai
  • 💰 هر تصویر ~$0.04
  • مدل‌های ویرایش: kontext، nanobanana-2، seedream

🖼️ ویرایش تصویر با Gemini (✅ رایگان!)

  • 🔑 API key رایگان از aistudio.google.com
  • مدل gemini-2.5-flash یا gemini-3.1-flash-image انتخاب کن
  • عکس ضمیمه + پرامپت بنویس
  • خودکار تصویر ویرایش‌شده برمیگرده ✅
  • 🎯 بهترین گزینه رایگان برای ویرایش تصویر

📋 ضمیمه عکس

  • 📎 دکمه پیوست
  • Ctrl+V پیست از کلیپ‌بورد
  • Drag & Drop کشیدن عکس به صفحه

⚡ سوییچ سریع

  • از نوار پایین صفحه بین provider‌ها سوییچ کن
  • وقتی عکس ضمیمه کنی، پیام سوییچ خودکار نشون داده میشه

📤 خروجی
